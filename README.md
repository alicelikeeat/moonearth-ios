# Moon Earth

独立 iPhone / iPad 3D 像素世界创作 App。SwiftUI + 原生 Liquid Glass，RealityKit 非 AR 场景。离线编辑，支持房屋内部设计和系统 AI 生成预览。

## 运行

需要 macOS、Xcode 26+、iOS / iPadOS 26+。

```sh
brew install xcodegen
xcodegen generate
open MoonEarth.xcodeproj
```

选择 `MoonEarth` Scheme。模拟器可直接运行；真机需设置自己的开发团队和签名。`project.yml` 是项目的唯一生成源，不需要第三方 Swift 依赖。纯数据内核可用 `swift test` 测试。

GitHub Actions 自动运行核心测试，构建模拟器和无签名真机 App，保存工程、App 和日志。无签名 `.app` 不能直接装到 iPhone，也不是已签名 IPA。

## 已接入的功能

- 项目新建、复制、重命名、删除与恢复；原子自动保存与上一版本恢复。
- 空白／平原／岛屿／山谷模板，128、256、512 格地图，固定种子地形。
- 地表笔刷、抬高／降低、压平，道路和水域绘制。
- 12 个可编辑房屋模板，移动、旋转、复制、锁定、楼层与尺寸修改。
- 室内分层、隐藏屋顶、房间拖绘、自动门洞、房间尺寸与位置修改。
- 0.25 米局部体素添加／开洞，家具选择、定位、旋转与锁定。
- 32 类原创程序物件 × 4 个尺寸变体（128 个目录条目），家具、厨卫、植物、灯具、户外设施；搜索与收藏。
- 世界／区域／建筑文件导入预览、导出与校验；撤销重做。
- 建筑占地、水域面积、道路连通性、入口和室内简化通行检查。
- Apple Foundation Models：房屋、当前建筑室内、周边街区；结构化输出、校验、预览、应用／取消。系统模型不可用时明确提示，另有标明“非 AI”的离线模板。

## 操作

打开“河畔工坊”示例。选择工具下单指旋转、双指平移、捏合缩放；点击建筑后“进入室内”，切换楼层。选“房间”拖出矩形，选“物件”从素材库放家具，选“体素／开洞”在指定楼层内高度编辑。

编辑工具下单指绘制，双指手势取消当前笔画并移动视角。每笔整体撤销。属性面板提供精确尺寸和位置调整。AI 或文件导入先进入预览，选择“检查”查看布局问题，确认“应用”才保存。

## 边界与验证

这是可继续开发的首版代码，**不宣称完整实现此前任务书的全部功能**。当前地形为高度场，不含任意地下洞穴；建筑内是可编辑体素结构。道路以地表格连通检查，不是完整交通／桥梁／隧道系统。水体为静态表面。尚未实现第一人称碰撞漫游、实时水流、任意自定义素材导入、截图导出、持久化操作日志和完整 GPU 预算系统。性能目标为 60FPS，必须真机测量，未提供虚构性能数字。

AI 是真实系统模型接口，但需支持 Apple Intelligence 的设备、地区与模型可用状态；没有云模型、API Key 或联网费用。自动生成布局仍可能需要手动调整，检查不代表真实建筑规范认证。

MoonPixel 完整双向互通**尚未完成**。已经只读核对其开发分支，提供有边界的单块桥接代码与测试；参见 [互通核验](docs/MOONPIXEL.md)。不会修改或覆盖 MoonPixel 存档。
