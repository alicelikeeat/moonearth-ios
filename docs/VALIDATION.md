# 验证记录与真机验收

本地执行环境为 Linux，无 Xcode、iOS Simulator 或 Swift 编译器。编译和核心测试由仓库的 `Moon Earth iOS` GitHub Actions 实际执行，结果以对应提交的工作流为准。

核心测试覆盖：文档往返与室内保留、损坏校验、未来版本拒绝、重复 ID、非有限坐标、坐标旋转、种子复现、撤销分支、门洞与分层剖切、体素挖空、区域截断、ID 重映射、锁定保护、道路高差、网格索引、素材目录、MoonPixel 未知字段原样保留、原子备份恢复。

未在当前环境验证的项目：真机安装、触控手感、Liquid Glass 动态效果、模型实际生成质量、长时间内存／热状态和 60FPS。编译通过不能替代这些验证。

真机检查步骤：

1. 在 iPhone 和 iPad 各运行一次，打开示例，检查拖动、捏合、双指中断笔画和选择建筑。
2. 创建两层建筑，绘制房间、增删家具、挖开门洞；切换楼层，再撤销和重做。
3. 锁定建筑／家具后尝试编辑和 AI 室内生成，确认锁定对象不被改变。
4. 生成 AI 方案后取消，确认原项目未变；重新生成并应用，确认可以手工编辑并撤销。
5. 导出三类文件、重开；损坏文件导入应提示错误并保留当前项目。
6. 编辑后后台切换、重新启动；确认已保存状态和备份恢复。不要把尚未落盘的更改当成恢复保证。
7. 256 格地图放置 100 栋房屋和 1000 个装饰，记录设备、系统、CPU/GPU 帧耗时、峰值内存、温度状态与 10 分钟结果。
8. 减少透明度、加大文字和 VoiceOver 下检查主要操作。

达不到目标时记录实际数据与瓶颈，不以空测试或模拟器帧率代替真机结论。
